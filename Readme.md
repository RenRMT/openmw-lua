# OpenMW lua mods

Collection of lua scripts and mods for OpenMW

## Mod list
- **CombatNotify**: adds a visual indicator if an NPC or creature engages the player in combat. For players who are hard of hearing or play with sound off.
- **BalanceOfPower** *(in development)*: a faction power and territory control framework, plus a foreign-invasion subsystem built on top of it. Split into a content-free framework mod and separate landmass data packs. See the [design document](BalanceOfPower/balance-of-power-design-doc.md) and [implementation plan](BalanceOfPower/implementation-plan.md).
