# OpenMW lua mods

Collection of lua scripts and mods for OpenMW

## Mod list
- **CombatNotify**: adds a visual indicator if an NPC or creature engages the player in combat. For players who are hard of hearing or play with sound off.
- **BalanceOfPower** *(in development)*: a faction power and territory control framework, plus a foreign-invasion subsystem built on top of it. Split into a content-free [framework](BalanceOfPower/BalanceOfPower_Framework/README.md) and separate landmass data packs — currently [Morrowind](BalanceOfPower/BalanceOfPower_Morrowind/README.md) (Vvardenfell and Solstheim). Note that Solstheim uses the **Anthology / Tamriel Rebuilt** position, not vanilla Bloodmoon's. See the [design document](BalanceOfPower/balance-of-power-design-doc.md), [implementation plan](BalanceOfPower/implementation-plan.md) and [next steps](BalanceOfPower/next-steps.md).
