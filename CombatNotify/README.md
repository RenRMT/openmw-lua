# Combat Notify — visual combat indicator (OpenMW)

Shows an "In Combat" indicator at the top of the screen while any NPC or
creature is engaging the player, and clears it when the last one disengages.
For players who are hard of hearing or play with sound off.

## Setup

Point `openmw.cfg` at the mod directory and enable its script list:

```
data="<path to>/openmw-lua/CombatNotify"
content=CombatNotify.omwscripts
```
